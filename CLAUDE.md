# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

The documentation and blog site for **gofs** (https://gofs.dev), a CLI that generates templates for full-stack Go apps (v2: Go standard library server, `html/template` pages, Lit web components as islands, sqlc for SQL, plain CSS; v1 used templ + HTMX, which v2 replaces). Built with Docusaurus 3 (classic preset), React 19, TypeScript. The gofs CLI itself lives in a separate repo (github.com/gofs-cli/gofs).

## Commands

```sh
npm install
npm start           # dev server with hot reload
npm run build       # static build into ./build — fails on broken links (onBrokenLinks: 'throw')
npm run serve       # serve the already-built ./build directory
npm run typecheck   # tsc
npm run clear       # clear Docusaurus cache if builds behave oddly
```

There are no tests or linter. `npm run build` is the main correctness check and is what CI runs.

## Structure and conventions

- **Docs** (`docs/`): the sidebar is fully autogenerated from the folder tree (`sidebars.ts`). Ordering comes from numeric filename/folder prefixes (`01-`, `02-` …), `sidebar_position` front matter, and `_category_.json` (`label`, `position`) in each subfolder. Docusaurus strips the numeric prefixes from URLs, so links between docs use the unprefixed path (e.g. `./prerequisites/required`).
- **Blog** (`blog/`): files named `YYYY-MM-DD-slug.md` with `slug`, `title`, `authors`, `tags` front matter. Authors must be defined in `blog/authors.yml` and tags in `blog/tags.yml` (inline ones only warn). Posts need a `{/* truncate */}` marker (HTML comments fail to compile because `future.v4` is on). Images go in `blog/img/`.
- **Landing page**: `src/pages/index.tsx` + `index.module.css`; global theme overrides in `src/css/custom.css`. Default color mode is dark.
- **Syntax highlighting**: `src/theme/prism-include-languages.js` is a swizzled theme component that registers a legacy `templ` Prism language (v1 docs only; v2 docs use ` ```html `, ` ```js `, ` ```go `, ` ```sql ` fences). Extra built-in Prism languages are added via `prism.additionalLanguages` in `docusaurus.config.ts`.
- **Design decisions for v2** (Lit islands, sqlc, vendoring, Baseline policy) are recorded in the gofs v2 Claude project docs; keep docs and blog consistent with them.

## Deployment

`.github/workflows/deploy.yaml` builds with Node 20 and deploys `./build` to GitHub Pages on pushes to `main` (PRs to `main` also run the build). `CNAME` sets the custom domain; `static/.nojekyll` must stay.
